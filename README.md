# MAC-Collector

WiFi 관리 프레임(인증·연결 요청)을 모니터 모드로 캡처해 주변 기기의 **MAC 주소를 수집·등록**하는 Qt6 기반 키오스크 프로그램입니다. 수집한 기기는 소유자 정보(이름·전화번호·기기종류)와 함께 서버에 등록되며, 서버가 다운되면 로컬 SQLite에 보류 저장했다가 복구 시 자동 재전송합니다.

## 주요 기능

- **패킷 캡처**: libpcap + Radiotap으로 802.11 관리 프레임(`auth`, `assoc-req`, `reassoc-req`)을 캡처, RSSI 임계값으로 가까운 기기만 선별
- **3단계 키오스크 UI**: ① 스캔/대기 → ② 정보 입력(등록·변경) → ③ 완료, 각 단계 음성 안내
- **서버 우선 동기화**: REST API(`/v1/devices/register|update|lists`)로 등록·변경·목록 동기화
- **오프라인 폴백**: 서버 다운 시 로컬 DB에 보류(`pending`) 저장 → 30초 주기로 자동 재전송
- **중복 판정**: 로컬 DB + 서버 목록을 모두 조회해 이미 등록된 기기는 "등록됨"으로 안내
- **관리자 페이지**: 등록 기기 검색·수정·삭제
- **장애 복원력**: 무선랜 down/제거, 권한 부족, 서버 다운 등을 감지해 프로그램을 죽이지 않고 상태 표시 + 재시도 버튼 제공

## 사전 요구사항

- Linux (Kali/Debian/Ubuntu)
- Qt 6.11.0 (Qt 온라인 인스톨러)
- CMake 3.19+
- `libpcap-dev`, `libsqlite3-dev`, `libgoogle-glog-dev`
- 모니터 모드 지원 무선랜 어댑터
- **서버 API 키** (서버 팀 발급) — 모든 REST 요청에 `x-api-key` 헤더로 사용. 없으면 프로그램이 실행되지 않습니다.

## 빌드 & 실행

```bash
sudo ./setup.sh                          # 의존성 설치 + 빌드 + sudoers 규칙 + API 키 입력(.env 생성)
./run.sh                                 # .env 에서 키 로드, 권한(cap_net_raw) 자동 적용 후 실행
```

> `setup.sh`는 설치 중 **API 키를 한 번 입력받아 `.env` 파일로 저장**합니다.
> `run.sh`는 `.env`에서 키를 읽어 환경변수로 넘긴 뒤, 재빌드로 사라진 `cap_net_raw,cap_net_admin` capability를 매 실행 시 자동 재적용하고 한글 입력기(fcitx5/ibus)를 설정한 뒤 실행합니다.

### API 키 설정 (필수)

키는 코드·git·바이너리에 넣지 않고 기기마다 `.env` 파일에만 보관합니다. **새 PC에서는 설치 시 한 번만 입력하면 됩니다.**

- **설치 중 입력** (권장): `sudo ./setup.sh` 실행 시 키를 묻습니다.
- **수동 등록/변경**: `.env` 파일에 아래 한 줄을 직접 작성합니다.
  ```bash
  echo 'MACCOLLECTOR_API_KEY=서버팀이_준_키' > .env
  ```

## 사용법

1. 실행하면 **설정 다이얼로그**가 뜹니다.
   - **인터페이스**: 모니터 모드 무선랜 (예: `mon0`)
   - **채널**: 1~14 (0이면 채널 고정 안 함, `iwconfig`로 설정)
   - **RSSI 임계값**: -100 ~ -20 dBm (이보다 약한 신호는 무시)
   - **DB 경로**: SQLite 파일 위치
2. **① 스캔**: 주변 기기가 잡히면 목록에 뜨고 음성 안내. 이미 등록된 기기는 "등록됨"으로 표시.
3. **② 입력**: 후보의 "등록"(신규) 또는 "변경" 버튼 → 이름·전화번호·기기종류 입력 후 확인.
4. **③ 완료**: 서버 전송(또는 오프라인 보류 저장) 후 완료 화면.
5. **관리자**: 우하단 버튼으로 진입, 등록 기기 검색·수정·삭제.

## 서버 연동

`src/main.cpp`의 `kApiBaseUrl`(기본 `https://ap-field.com`)로 백엔드와 통신합니다.

**모든 요청에는 인증 헤더 `x-api-key`가 포함됩니다.** 키 값은 환경변수 `MACCOLLECTOR_API_KEY`에서 읽으며(`run.sh`가 `.env`에서 로드), 키가 비어 있으면 프로그램이 시작 시 종료됩니다.

등록 -> `/v1/devices/register` 
변경 -> `/v1/devices/update` 
목록 -> `/v1/devices/lists` 
삭제 -> `/v1/devices/delete/{mac주소}` 

서버가 응답하지 않으면 로컬 DB에 `pending_op`(`register`/`update`/`delete`)로 보류 저장하고, 30초 주기 타이머와 `/lists` 응답 수신 시 자동 재전송합니다. 삭제 보류(`delete`)는 행을 즉시 지우지 않고 플래그로 숨긴 뒤, 서버 삭제가 확정되면 실제로 제거합니다.
